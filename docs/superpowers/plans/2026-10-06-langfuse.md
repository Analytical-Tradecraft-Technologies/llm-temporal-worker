# Langfuse implementation plan

Goal: implement the approved operation tracing design in the existing PR #1232.
Architecture: capture semantic provider input before dispatch in the existing
encrypted cloud repository; reconstruct finalized output from durable execution
records; send OTLP HTTP JSON in a dedicated bounded Temporal activity.
Stack: Go, Temporal Go SDK, existing cloud event/blob repository, Langfuse OTLP.
Spec: `docs/superpowers/specs/2026-10-06-langfuse-design.md`.
Constraints: no new database or infra; tracing failure cannot affect LLM results;
OpenRouter defaults off; preserve caller identity and provider-specific prices.
Review focus: authorization, request capture, replay, retry bounds, cost semantics.

1. Add config tests for disabled defaults, credential validation and endpoint
   overrides. Implement `config.LangfuseConfig`, schema and snapshot copying.
2. Add HTTP fixture tests for `langfuse.Client.Export`: Basic auth, v4 headers,
   caller metadata, provider metadata, costs, partial success and safe failures.
   Implement a dedicated OTLP HTTP JSON encoder with bounded body/timeout.
3. Add repository tests for encrypted immutable capture, scope checks, attempt
   enumeration and export acknowledgment. Implement cloudstate telemetry storage
   using existing event/blob primitives, including bounded leases.
4. Add runtime tests for provider capture before dispatch, eligibility and
   finalized operation export. Wire credentials through the snapshot factory,
   expose `ExportLangfuseV1`, and preserve original timing and pricing.
5. Add Temporal tests for successful and failed exports, bounded retry options,
   terminal failures and old-history version gating. Register the optional final
   activity and invoke it without changing operation outcomes.
6. Document configuration and caller attribution. Run focused tests after each
   red/green cycle, then the Go suite and repository checks. Review the diff,
   commit and push to the existing PR; update its title, body and labels.
